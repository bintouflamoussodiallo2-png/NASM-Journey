# Exercice 13 — Implémenter atoi

## Objectif
Convertir une chaîne de chiffres ASCII en entier (`int`), comme la fonction `atoi`.

## Fichiers
- `ex13.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex13.asm -o ex13.o`
- `gcc ex13.o -o ex13`

## Exécution
- `./ex13`

## Output
Valeur: 1234
(pour une entrée "1234").
