# Exercice 03 — Afficher un entier avec printf

## Objectif
Appeler la fonction C `printf` pour afficher un entier en respectant la convention d'appel System V.

## Fichiers
- `ex03.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex03.asm -o ex03.o`
- `gcc ex03.o -o ex03`

## Exécution
- `./ex03`

## Output
Valeur: 42
