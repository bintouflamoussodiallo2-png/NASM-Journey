# Exercice 08 — Boucle avec condition (tant que > 0)

## Objectif
Implémenter une boucle qui décrémente une valeur tant qu'elle est strictement positive.

## Fichiers
- `ex08.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex08.asm -o ex08.o`
- `gcc ex08.o -o ex08`

## Exécution
- `./ex08`

## Output
Affichage des valeurs successives jusqu'à 0 (ou un message indiquant la fin).
