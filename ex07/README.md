# Exercice 07 — Boucle simple (compter de 5 à 1)

## Objectif
Afficher les nombres de 5 à 1 en utilisant une boucle avec `dec` et `jmp`.

## Fichiers
- `ex07.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex07.asm -o ex07.o`
- `gcc ex07.o -o ex07`

## Exécution
- `./ex07`

## Output
5
4
3
2
1
