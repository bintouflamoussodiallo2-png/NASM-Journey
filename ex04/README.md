# # Exercice 04 — Lire un entier avec scanf

## Objectif
Lire un entier depuis l'entrée standard avec `scanf` et l'afficher ensuite.

## Fichiers
- `ex04.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex04.asm -o ex04.o`
- `gcc ex04.o -o ex04`

## Exécution
- `./ex04`

## Output
Le programme demande un entier, puis affiche la valeur lue.
