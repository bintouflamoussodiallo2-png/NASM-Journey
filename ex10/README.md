# Exercice 10 — Trouver le maximum dans un tableau

## Objectif
Parcourir un tableau d'entiers et déterminer la valeur maximale.

## Fichiers
- `ex10.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex10.asm -o ex10.o`
- `gcc ex10.o -o ex10`

## Exécution
- `./ex10`

## Output
Max: 42
(ou la valeur maximale réelle du tableau.)
