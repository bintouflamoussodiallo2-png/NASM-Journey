# Exercice 14 — Mini-calculatrice (+, -, *, /)

## Objectif
Lire deux entiers et un opérateur (`+`, `-`, `*`, `/`), effectuer l'opération et afficher le résultat.

## Fichiers
- `ex14.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex14.asm -o ex14.o`
- `gcc ex14.o -o ex14`

## Exécution
- `./ex14`

## Output
Résultat: 8
(par exemple pour 3 + 5).
