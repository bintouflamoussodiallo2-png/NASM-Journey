# Exercice 09 — Manipuler un tableau d'entiers

## Objectif
Parcourir un tableau d'entiers en mémoire et afficher chaque élément.

## Fichiers
- `ex09.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex09.asm -o ex09.o`
- `gcc ex09.o -o ex09`

## Exécution
- `./ex09`

## Output
Affichage des éléments du tableau, un par ligne.
