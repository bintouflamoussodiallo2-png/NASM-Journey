## Objectif
Additionner deux entiers (constants ou lus) et afficher le résultat.

## Fichiers
- `ex05.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex05.asm -o ex05.o`
- `gcc ex05.o -o ex05`

## Exécution
- `./ex05`

## Output
Somme: 7 
(ou une autre valeur selon les nombres choisis.)
