# Exercice 06 — Comparer deux valeurs

## Objectif
Comparer deux entiers et afficher un message indiquant si le premier est `<`, `=`, ou `>` au second.

## Fichiers
- `ex06.asm` : code source NASM.

## Compilation
- `nasm -f elf64 ex06.asm -o ex06.o`
- `gcc ex06.o -o ex06`

## Exécution
- `./ex06`

## Output
A < B ou A = B ou A > B
